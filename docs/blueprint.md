# **App Name**: ProjectPro

## Core Features:

### Project Management
- Modern project catalog with glassmorphism UI
- Category-based project filtering with animated transitions
- Detailed project pages with responsive layouts
- Project kit downloads with secure authentication
- Direct contact system for project inquiries

### User Experience
- Responsive dark mode interface
- Smooth animations and transitions
- Mobile-optimized layouts
- Glassmorphism effects across all UI elements
- Intuitive navigation with visual feedback

### Technical Features
- Next.js-based architecture
- Tailwind CSS for styling
- Firebase integration
- AI-powered project summarization
- Real-time user interactions

### Performance
- Optimized image loading
- Smooth scrolling and animations
- Responsive to all screen sizes
- Fast page transitions
- Efficient state management

## Style Guidelines:

### Theme
- Dark mode exclusive design with a modern, professional aesthetic
- Deep navy blue background (HSL 225 45% 7%) for enhanced glassmorphism effects
- Light text (HSL 213 31% 91%) for optimal contrast and readability

### Color Palette
- Primary: Bright blue (HSL 221 83% 53%) for interactive elements and CTAs
- Secondary: Electric blue (HSL 199 89% 48%) for accents and highlights
- Accent: Same as secondary for consistency
- Destructive: Bright red (HSL 0 84% 60%) for warning actions
- Muted: Navy blue (HSL 223 47% 20%) for subtle elements

### Glassmorphism Effects
- Backdrop blur effects (16px) with increased saturation (180%)
- Semi-transparent backgrounds with subtle borders
- Layered shadows for depth perception
- Subtle white borders (0.1 opacity) for definition
- Enhanced contrast between elements

### UI Components
- Modern rounded corners (0.75rem to 1.5rem)
- Geist Sans font family for clean typography
- Interactive hover states with subtle elevation
- Smooth transitions (0.2s - 0.3s ease)
- Gradient overlays for added depth

### Layout
- Responsive grid system for project cards
- Full-width mobile layouts with proper spacing
- Safe area insets for modern device compatibility
- Proper text wrapping and overflow handling
- Flexible container widths with max-width constraints

### Interaction Design
- Subtle scale and elevation changes on hover
- Background opacity transitions for state changes
- Consistent animation timing (0.2s - 0.3s)
- Enhanced focus states for accessibility
- Clear visual feedback for interactive elements
